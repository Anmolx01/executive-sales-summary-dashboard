# Executive Sales Summary Dashboard

## Overview

An executive-level Power BI dashboard developed during my Data Analytics internship at DataMelon Labs.

The dashboard provides a consolidated view of business performance across sales, transactions, customers, loyalty, regions, departments, categories, payment methods, age groups, cities, and store formats.

## Key Features

- Executive KPI overview
- Sales and transaction analysis
- Customer and spend-per-customer analysis
- Loyalty sales analysis
- Loyalty transaction analysis
- Regional performance
- Department sales and loyalty participation
- Category contribution analysis
- Top city performance
- Store-format analysis
- Loyalty tier distribution
- Payment method distribution
- Customer age-group analysis
- Monthly sales trend analysis

## Tools & Technologies

- Power BI
- DAX
- Power Query
- Data Modeling
- Data Visualization
- Business Intelligence

## Key Metrics

- Total Sales
- Transactions
- Average Transaction Value
- Customers Shopped
- Spend Per Customer
- Loyalty Sales
- Loyalty Transactions
- Loyalty Sales %
- Customer Penetration
